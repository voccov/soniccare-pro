# Phase 1 interactive mockup

The mockup lives at `web/mockup.html` and is published at
<https://voccov.github.io/soniccare-pro/mockup.html>. It uses **example data**; it is not
a measurement and not the app.

The seven segments at the top jump between screens. The in-screen buttons drive the flow:
the readiness checklist unlocks Continue, the left ping asks which ear, the Settings path
reveals the scratch check, the measurement runs the left ear and then the right-ear
switch, and the result leads to cleaning and the dry timer.

What it is for:

- Review the interaction and the amount of text per screen.
- Check the one-microphone-at-a-time model and the right-ear switch.
- Check the inline Settings path that replaces PiP in the MVP.
- Check the motion and the empty/disabled states before native work.
