Native · Phase 0B self-test

Install SonicCare Pro

This is the native SwiftUI self-test build. It checks microphone permission, the AirPods HFP route, sample rate, live RMS, haptics, and the floating PiP guide.

Install in SideStore

SideStore must already be installed, signed in, and refreshed. Open this page in Safari, not an in-app browser. The app is unsigned until SideStore signs it on your iPhone.

Before you tap

1. SideStore is installed and refreshed.
2. LocalDevVPN is connected.
3. You are using the spare Apple ID.

If the button does nothing, SideStore is not installed yet. Finish the one-time SideStore setup first. If SideStore shows an error, send the exact text or a screenshot.

Download the IPA instead

After install

Open SonicCare Pro, allow microphone access, and run the self-test. The app expires in 7 days; SideStore refreshes it while LocalDevVPN is connected. Your results stay on the iPhone.
